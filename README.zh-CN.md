cx 把亚马逊的每期结算和回款对上，说清每笔差额从哪来；再扣掉亚马逊的各项费用和你的成本，算出每个商品赚了多少。成本用你在亚马逊后台填写的，或你告诉 cx 的。cx 读取你连接的每个站点的交易、费用、退款、赔偿和结算。

你可以这样问：

- 为什么上一笔回款比销售额少这么多？
- 上个月亚马逊为什么扣了我信用卡里的钱？
- 德国站结算里哪些行带增值税，由谁缴？

如果想知道库存压着要花多少钱、什么时候该补货，再装上 cx-amazon-stock-playbook。

## 用到的数据

- **Amazon SP-API**：你的亚马逊卖家账户，在 Amazon SP-API 插件里连接。cx 在这里读取交易、结算、回款和费用。
- **Amazon Ads**（如果你装了）：亚马逊的单品数据读不到时，cx 从这里读每个商品的广告花费。
