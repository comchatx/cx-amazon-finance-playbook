cx 把亚马逊的每笔回款和你的银行到账对上，并算出每个产品扣掉亚马逊费用和你自己的成本后赚了多少。它通过 Amazon SP-API 插件，读取你在那里连接的每个站点的交易、费用、退款、赔偿和结算。

你可以这样问：

- 为什么上一笔回款比销售额少这么多？
- B0EXAMPLE1 上个月扣掉费用和进货成本后赚了多少？
- 德国站结算里哪些行带增值税，由谁缴？

广告赚的钱够不够付广告费，归赞助广告手册；库存和补货，归库存手册。

## 需要

- **Amazon SP-API**：你的亚马逊卖家账户，在 Amazon SP-API 插件里连接。cx 在这里读取你的钱。
- **Amazon Ads**（如果你装了）：每个产品的广告花费，用在亚马逊自己的单品数据对你不开放的时候。

两者各是一个插件，价格见各自的页面。
